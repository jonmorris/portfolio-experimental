# One fixed content model for every project

_Decided 2026-06-23._

Every project (work or side) renders from the same frontmatter snapshot: `title`, `name`, `type`, `year`, `role`, `client`, `skills`, `summary`, `cover`. That keeps the feed uniform and lets one template serve every project. The `tech` field was renamed `skills` because the portfolio is about what the person did (capabilities), not just the stack, and "skills" reads correctly for both design-led and build-led work.
