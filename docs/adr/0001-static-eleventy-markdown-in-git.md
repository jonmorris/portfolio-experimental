# Static Eleventy site, all content Markdown in git

_Decided 2026-06-22._

The site is a static Eleventy build: every project, post and page is Markdown with frontmatter, committed to git, with no backend, database or CMS. That's the simplest thing that ships and stays maintainable for a one-person portfolio. The tradeoff is that authoring means editing a text file and committing, not using an editor UI. See `README.md` → Project structure.
