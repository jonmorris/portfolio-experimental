# Blog drafts live in the repo, unpublished

_Decided 2026-06-24._

Blog ideas are real Markdown files from the moment they're captured, but a draft sets `permalink: false` and `eleventyExcludeFromCollections: true` so it never builds. Publishing means deleting those two lines. Ideas stay under version control and reviewable in a PR, with no separate drafts system and no risk of shipping a half-written post.

Note: since the repo went public on 2026-11-20, drafts are readable on GitHub even though they're not on the site.
