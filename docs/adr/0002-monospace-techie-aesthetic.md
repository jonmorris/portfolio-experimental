# Monospace throughout, with a dark/light toggle

_Decided 2026-06-22._

Type is JetBrains Mono everywhere, for a techie, content-first look, with a dark/light theme toggle. The aesthetic is a deliberate signal about the work, not a default; a reader expecting a conventional proportional-type portfolio should not "fix" it. Tokens live in `src/css/style.css`.
